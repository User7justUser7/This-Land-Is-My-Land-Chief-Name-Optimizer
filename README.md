# THIS LAND IS MY LAND - CHIEF NAME OPTIMIZER & PREDICTOR v1.0.2

A powerful, high-performance desktop tool for **This Land Is My Land** that predicts Chief stats, scans optimal Chief Name builds, and generates thousands of lore-friendly heterogram display names.

---

## 🚀 FEATURES

- **Chief Name Optimizer**: Scan through 67.1 Million seed combinations across 2.54 Million dictionary translations to discover the absolute highest-ranking Chief Names for your playstyle.
- **Chief Name Generator**: Enter any custom name or raw letter string to generate thousands of alternative lore-friendly names that produce 100% identical in-game stats.
- **Chief Name Predictor**: Calculates exact in-game stats for 1 specific name across all 12 Spirit Animals simultaneously.
- **Custom Stat Ranking Profiles**: Rank stats in the exact order you care about (e.g., Health → Weight → Stamina → SP → Warriors) with 1-click Profile Presets (+ SAVE, X DEL, Lock Profile).
- **Persistent Favorites List**: Save your favorite Chief Names across sessions with 1-click (+ FAV), double-click to view instant Predictor stats, and export your list to `.txt` or `.csv` files.
- **4 Custom Themes**:
  - **Terminal Green (Classic)**: High-tech retro matrix aesthetic.
  - **Resistance Crimson (Game Theme)**: Dark charcoal grey with game-inspired crimson accents.
  - **Clean Light (Basic White)**: Soft Windows XP-style light mode (`#E2E6EE`).
  - **Antigravity (Dark Teal)**: Sleek dark teal workspace with luminous turquoise and warm amber gold headers.

---

## 📁 FILES & DIRECTORY STRUCTURE

### Files Created Automatically at Runtime (Saved in %APPDATA%\TLIMLNameOptimizer):
- `options.json`: Stores your active theme, window size, auto-fit preferences, and locked profile state.
- `user_presets.json`: Stores your custom saved rank stat profiles (+ SAVE).
- `favorites.json`: Stores your saved favorite Chief Names automatically across sessions.
