==========================================================================================================
                               THIS LAND IS MY LAND  --  CHIEF NAME OPTIMIZER & PREDICTOR v1.0.2
==========================================================================================================

   A high-performance desktop optimization suite for "This Land Is My Land". Predict Chief stats instantly, scan 67.1 Million
   seed combinations across 2.54 Million dictionary translations, or generate thousands of lore-friendly heterogram names
   that produce 100% identical in-game Chief stats.

==========================================================================================================
   [1] FEATURES & CAPABILITIES
==========================================================================================================

   * OPTIMIZER TAB:
     - Searches through 67.1 Million seed combinations across 2.54 Million in-game name translations.
     - Custom Stat Ranking: Prioritize stats in the exact order you care about (Health, Weight, Stamina, SP, Warriors).
     - Save & Lock Rank Profiles: Save custom stat priorities with (+ SAVE) and delete unwanted profiles with (X DEL).
     - Must Contain Filter: Filter searches for specific words or letter combos (e.g., "Thunder, Bear" or "Eagle").
     - Skill Requirements: Filter Chief builds that grant specific skills (e.g., Silent Move, Health Boost, Heavy Weapons).
     - Word Category Checkboxes: Toggle Colors, Animals, Nature, Adjectives, Tribes, Cultural, and Historical word pools.

   * GENERATOR TAB:
     - Generates thousands of alternative lore-friendly Chief names for ANY input name or raw letter string.
     - Order-Preserving Signature Matching: Every generated name is 100% guaranteed to produce identical in-game stats.
     - Duplicate Standalone Word Filtering: Automatically filters out duplicate words.
     - Clean Alphabetical Listing: Results are automatically listed in clean A-Z alphabetical order.

   * PREDICTOR TAB:
     - Calculates exact in-game stats for 1 specific name across all 12 Spirit Animals simultaneously.
     - Sub-second instant stat calculations for any Chief Name and month.

   * FAVORITES SIDEBAR:
     - Save your favorite Chief builds with 1-click (+ FAV).
     - Double-Click Lookup: Double-click any name in your Favorites list to instantly open it in the Predictor tab and view all 12
       spirit animal stats.
     - Export File: Export your saved favorites list to .txt or .csv files via the (EXPORT FILE) button or right-click menu.
     - Persistent Storage: Favorites automatically save and reload across sessions.

   * OPTIONS & TABLE CONTROLS:
     - Auto-Fit Columns: Auto-resizes table columns to content width. Right-click any results table and select 'Auto-fit Columns'.
     - 4 Color Themes: Terminal Green (Classic), Resistance Crimson (Game Theme), Clean Light (Basic White), and Antigravity (Dark Teal).

==========================================================================================================
   [2] FILES & DIRECTORY STRUCTURE
==========================================================================================================

   * AUTO-GENERATED SAVED STATE FILES (Saved automatically in %APPDATA%\TLIMLNameOptimizer):
     - options.json                 (Stores your active theme, window size, & options)
     - user_presets.json            (Stores your custom saved rank stat profiles)
     - favorites.json               (Stores your saved favorite Chief Names)

==========================================================================================================
   [3] SYSTEM REQUIREMENTS
==========================================================================================================

   * Operating System : Windows 10 / Windows 11 (64-bit)
   * Memory           : 512 MB RAM minimum
   * Runtime          : Standalone Single-File (.NET 10 pre-bundled)
